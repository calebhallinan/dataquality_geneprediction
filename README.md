## Impact of Data Quality on Gene Prediction from Histology Images via Deep Learning

This repository contains the code used to analyze the impact of data quality on gene prediction from histology images via deep learning using a serial section breast cancer dataset. Also, the iStar code was used and can be downloaded from the repo [here](https://github.com/daviddaiweizhang/istar).

More details can be found here: https://www.biorxiv.org/content/10.1101/2025.09.04.674228v1
